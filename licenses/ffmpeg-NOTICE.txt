Riptag's packaged app includes FFmpeg, a separate program it runs as a process.

The full licence is in ffmpeg-LGPL-2.1.txt beside this file.

This build is unmodified FFmpeg source, configured to include only what Riptag
needs, with no GPL or nonfree components.

Source code:
  https://ffmpeg.org/releases/ffmpeg-8.0.1.tar.xz
  SHA-256 05ee0b03119b45c0bdb4df654b96802e909e0a752f72e4fe3794f487229e5a41

The exact build steps and options are in scripts/build-ffmpeg.sh:
  https://github.com/Redseb/riptag/blob/main/scripts/build-ffmpeg.sh

To use your own build, replace the file named ffmpeg beside the Riptag program
(Riptag.app/Contents/MacOS/ffmpeg on a Mac).
